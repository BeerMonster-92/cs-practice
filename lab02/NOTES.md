рабочая папка это та, в которой пишется код, он никак не связан с репозиторием, сохранение рабочего файла происходит на жесткий диск
индекс это промежуточная зона, в которую рабочий файл попадает после команды git add ...
коммит это следующий этап движения рабочего файла, финальный, дальше только git push, git commit записывается в историю репозитория, обязательно нужно писать комментарий

git - это программа, используемая для контроля версий, невероятно полезный инструмент каждого, кто работает с кодом
github - это среда, сайт, на который выгружают репозитории, на который коммитят с помощью гита


использованные команды: git diff сравнивает рабочую папку и индекс, а git diff --staged сравнивает состояние индекса с последним коммитом
git status проверяет сразу три зоны: рабочую папку, индекс и последний коммитом


ветки: это отдельные части одного репозитория, в гите мы указываем в какую ветку отправляем коммит, остальные ветки при этом не меняются, при новом коммите гит запоминает, какой был коммит до этого (родителя), при слиянии мы сливаем коммиты из одной ветки в другую
